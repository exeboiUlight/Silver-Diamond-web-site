Игровой движок без лишнего веса

Silver Diamond Game Engine — компактный, но полноценный движок на чистом C99. Один шейдер для всего: PBR-lite, текстуры и скелетная анимация из glTF/GLB, свой сканер JSON и атлас шрифтов, физика 2D/3D, spatial-аудио и редактор сцен. Собран одним человеком — с вниманием к каждой строке.

Документация Посмотреть возможности
main.c 
#include <sdge.h>

sdge_window *w = sdge_create_window(1280, 720,
                                    "Hello SDGE", NULL);
sdge_make_context_current(w);
sdgr_init();
sdui_init();

sdge_camera3d cam;
sdge_camera3d_init(&cam, 55.f, 16.f/9.f, .1f, 200.f);
sdge_camera3d_orbit(&cam, (float[]){0,0,0}, 6.f, .7f, .4f);

sdge_model *hero = sdge_model_load("hero.glb");
sdge_model_play(hero, 0, 1);

/* loop */
while (!sdge_window_should_close(w)) {
    sdge_poll_events();
    sdge_camera3d_update(&cam);
    sdgr_begin_frame(NULL);
    sdgr_set_camera(cam.view, cam.proj, cam.pos);
    sdge_model_draw(hero, NULL);
    sdgr_end_frame();
    sdge_swap_buffers(w);
}

Что умеет движок

Все модули писались с нуля под одну задачу — дать разработчику минимум, который работает.

🎨

Forward PBR-lite рендер

Один GLSL-шейдер на весь мир. Ambient, sun и до 8 point lights, GGX-спекуляр,
frustum culling по bounding sphere.

🖌️

Текстуры и материалы

До пяти слотов на материал: base color, metallic-roughness, normal, occlusion, emissive.
sRGB для цвета, alpha-режимы, KHR_texture_transform — через stb_image.

📦

glTF 2.0

Загрузчик .glb и .gltf + .bin: несколько буферов, percent-encoded пути,
UTF-8 BOM, нормализованные accessor'ы. Тяжёлые сцены — в одной арене.

🦴

Скелетная анимация

LINEAR / STEP / CUBICSPLINE, топологический порядок и ленивый семплинг,
кэш skin-палитры. Скиннинг (joint, weight) × 4 интерливится в GPU.

🖼️

UI на SDF

Скруглённые боксы вычисляются прямо в шейдере, текст — из атласа глифов.
Один батч — один draw call на весь интерфейс.

🔤

Свои шрифты

Полноценный растеризатор TTF (glyf) и OpenType/CFF (Type 2 charstring).
Атлас растёт по мере надобности, встроенный 5×7 всегда под рукой.

⚙️

2D и 3D физика

Круги/сферы и OBB, SAT по 15 осям, sequential impulses, трение и sleep.
Ориентация — кватернион, инерция — диагональный тензор, стабильные указатели на тела.

🔊

Spatial-аудио

Свой миксер 48 кГц с inverse-distance attenuation, equal-power pan,
Doppler и low-pass фильтром «воздуха». WAV и MP3 из коробки.

🧰

Редактор сцен

Дерево узлов, гизмо move/rotate/scale с ограничением по оси и наложение текстуры
на отдельный узел. Экспорт в glTF 2.0 + .bin с встроенными изображениями.

Почему именно Silver Diamond

Не «ещё один движок», а собранный под реальные задачи инструмент.

Прозрачный и предсказуемый код

  • Чистый C99, никаких скрытых аллокаций на кадр.
  • Арена-аллокатор: загрузка модели = O(#блоков) malloc'ов, освобождение = один вызов.
  • Никаких C++ рантаймов и «умных» указателей — только то, что видно в коде.

Минимум зависимостей

  • glad подключается внутри рендерера — приложение не видит GL-заголовков.
  • Свой JSON-сканер (jsmn-style), свой WAV-декодер, свой CFF-парсер.
  • Внешних библиотек всего три: glad (загрузчик GL), stb_image и minimp3; окно — напрямую Win32/X11.

Готов из коробки

  • 2D UI с SDF-боксами и атласом шрифтов — ничего не надо рисовать самому.
  • 2D-камера, 3D-камера (orbit / fps / look-at), источники света.
  • Менеджер сцен с fade-переходом.
  • Редактор сцен в том же репозитории.

Один автор — цельный дизайн

  • Все модули пишутся одним человеком — соглашения одинаковые во всём API.
  • Нет «зоопарка» стилей: префиксы (sdge_, sdgr_, sdga_, sdph3_) фиксируют границы модулей.
  • Быстрее отклик на баг-репорты и обсуждение новых фич.

Кроссплатформенность

  • Windows (Win32 + WGL) и Linux (X11 + GLX) из коробки.
  • Один и тот же исходник собирается в DLL и в статическую библиотеку.
  • Переключение режима — через один define: SDGE_BUILD_DLL / SDGE_USE_DLL.

Формат, который переживёт движок

  • Сцены редактора — обычный glTF 2.0, открываются в любом вьюере.
  • Экспорт редактора — glTF 2.0 + .bin, изображения встроены как data-URI: пара файлов открывается в любом вьюере.
  • Не нужно конвертировать ассеты через сторонние тулзы.

Документация движка

Полный справочник по API, туториалы по рендеру, физике, аудио и редактору сцен — всё в одном месте.
